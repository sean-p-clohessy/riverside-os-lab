# Riverside OS Lab

Level 5 Unit 50 Operating Systems: six original teaching investigations for Weeks 6 and 7.

Open `index.html` through a static web server or GitHub Pages. For direct offline opening, use `Riverside_OS_Lab_Offline.html`.

No dependencies, sign-in, backend, analytics or real-system commands. Progress lives in localStorage with JSON export/import. Local practice scores are editable and not authenticated assessment evidence. Written explanations require tutor review.

Models: lost update and mutex; two-resource deadlock; CPU/device batch pipeline; simplified POSIX-style permissions; finite volatile buffer; fixed-priority constrained controller. All numerical data are illustrative. This is not an OS emulator.

Academic sources and model limits are linked in the app. `resources.html` contains the lecture downloads and lesson pages.

GitHub Pages: deploy main branch, root folder. Offline file is generated from index.html, styles.css, models.js and app.js; rebuild it after changes.
